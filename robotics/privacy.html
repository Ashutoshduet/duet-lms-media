Privacy Policy — DUET Robotics Lab 360

Effective date: 22 November 2026 · Publisher: DUET STEM, a unit of Duet Power Private Limited, India

DUET Robotics Lab 360 is a 3D electronics bench for school students. Students place parts on a breadboard, wire them to an Arduino-compatible board, write code and watch the circuit work, on Meta Quest headsets, Android phones and tablets, computers and classroom panels.

What we collect

The app has no sign-up with a password or email. It does not ask for email addresses, phone numbers, photos, voice recordings or location. A student may type a name and roll number for their own progress on a shared device (see “Student profiles and live classes”). It uses no advertising, no analytics and no tracking tools, and it does not include any third-party data-collecting software. Information reaches us only in two cases: the small device-register entry described under “Subscription codes”, sent once when a school activates its code, and, only if a student joins a teacher's live class, that student's lesson results (see below).

What stays on your device

  • Settings such as the chosen language (English, Hindi or Hinglish), sound on or off, the lessons completed and the sketch written in Free build.
  • Student profiles, if used: each student's name and roll number, lessons, stars, certificates and best times.
  • The subscription activation: a scrambled fingerprint of the school's subscription code, its end date and the school's name.
  • The app's own files, kept so that the app also works offline. The sketches students write run inside the app on the device; they are never uploaded.

This information is kept on the device; apart from the device-register entry and, for a student who joins a live class, that student's lesson results (both described below), it is not sent to us. Clearing the app's data or uninstalling the app removes it.

Subscription codes

Schools receive a subscription code from DUET STEM. To check a code, the app downloads a list of scrambled code fingerprints from our website and compares them on the device; the code itself is never sent to us or to anyone else.

A code is sold for a set number of devices. When a code is activated, the app tells the DUET STEM device register (a small service we run on Google Apps Script) the scrambled fingerprint of the code, a random device number created by the app, the kind of device (for example "Meta Quest") and the school's name, so that each code is used on no more devices than were bought. We use this only to count the devices on each code, and keep it while the code is valid. We do not sell or share it. A school can ask us to remove one device or all of its entries at any time by writing to info@duetpower.in.

Camera

The camera is used only when a student taps "Scan" to read the QR code on a DUET STEM kit. The picture stays on the device and is not recorded or sent.

Internet connection

The app downloads its 3D models and narration from our website, which is hosted on GitHub Pages. Like any web host, GitHub may record technical information such as the device's IP address in its server logs; see the GitHub Privacy Statement. We do not receive or use this information to identify anyone.

Student profiles and live classes (optional)

Profiles. On a shared device (a lab computer, a classroom panel, a headset), students can tap “Sign in” and type their name and, if they like, a roll number, so that each student's lessons, stars, certificates and best times are kept apart. Profiles are kept on the device only.

Live classes. A teacher can make a class and give students its 6-letter class code. If a student joins with that code, each lesson the student finishes is sent to the DUET STEM class service (a small service we run on Google Apps Script, with its data in a Google Sheet in DUET STEM's Google account): the student's name and roll number as typed, a random student number, a random portfolio key, and the lesson's result (stars, score, time, mistakes, hints used and date). The teacher sees these in the class dashboard, and a principal who enters the school's DUET STEM code sees the classes of that school. A class joined with the teacher's QR code, without the internet, sends nothing to us: the student shows a hand-in QR code to the teacher instead.

In a headset (Meta Quest and other VR headsets), live classes by code and the portfolio link are switched off: a student's name and results stay on the headset and are never sent anywhere.

Portfolio for parents. A student can share a portfolio link (it contains the random portfolio key). Anyone who has the link can see that student's name and lesson results, so it should be shared only with parents or teachers.

We use class data only to show it to the teacher, the school and the student's family, never for advertising, and we do not sell or share it. We keep it while the school uses the class. A teacher or school can ask us to delete a class, a student or all of a school's data at any time by writing to info@duetpower.in.

Virtual reality

In VR, the headset's position, controller and hand tracking are processed on the device by the headset and its browser so that the lab responds to movement. The app does not record or send this data. In the headset, the app does not use the headset's cameras or record the microphone.

Children

The app is made for use in schools, under the supervision of teachers. The only personal information it can hold is a student's name and roll number, typed by the student or teacher, and it sends them only to the teacher's live class that the student chose to join. On Meta Quest headsets it is meant for users of the age Meta allows (10 years and over).

Changes
