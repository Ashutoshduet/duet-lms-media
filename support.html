Help & Support

For DUET Science Lab 360, DUET Human Body 360, DUET Solar System 360 and DUET Drone Simulator on Meta Quest and in web browsers. Publisher: DUET STEM, a unit of Duet Power Private Limited, India.

Problem, question or complaint? Write to us:

info@duetpower.in

Please tell us: your school's name, the app's name, the headset (for example Quest 3 or Quest 3S), what you did and what went wrong, and when it happened. A photo or screenshot helps a lot. Do not send your full school code by email; the first four letters are enough for us to find it.

Quick fixes

  1. "No internet" on the code screen: connect the headset to Wi-Fi once. The code is checked and the app saves itself on the headset; after that it works without internet until the code's end date.
  2. Code not accepted: check every letter and number again (the code has 12 after "DUET"). Make sure the code is for this app and that the subscription has not ended. If it still fails, write to us.
  3. Free demo: without a code each app opens a small free part. Everything else asks for the school's code.
  4. The app is stuck or the screen stays black: close the app from the Quest menu and open it again. If that does not help, restart the headset (hold the power button, then Restart).
  5. Too low or too high in the lab (sitting down, Science Lab 360): use the Height buttons in the menu.
  6. Updates: the apps update themselves when they are opened with internet. Nothing needs to be reinstalled.

Privacy

The apps collect no personal information. Read each app's privacy policy: Science Lab 360 · Human Body 360 · Solar System 360 · Drone Simulator
