# duet-lms-media
DUET STEM web apps on GitHub Pages (ashutoshduet.github.io/duet-lms-media/).

## LMS lesson media (videos, walkthroughs, pictures, 3D models)
Their home is **https://duetpower.in/lms/media/library/** (moved there because this Pages site was over the 1 GB limit).
Nothing was deleted:
- the `media-archive` branch keeps every file that was here (the lesson videos `*.mp4`, `assets/`, `walkthrough/`,
  `plates.js`) plus `media-manifest.json`, the list (size and SHA-1 of each file) that duetpower.in copies;
- `Ashutoshduet/duet-lms-media-2` is unchanged (duetpower.in keeps a copy in `library/2/`).

An old link to a moved file opens the same file on duetpower.in (`404.html`). The tools are in `devtools/mirror/`.
